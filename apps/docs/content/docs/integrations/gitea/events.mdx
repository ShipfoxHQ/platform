This reference lists the Gitea push event that Shipfox delivers to a Gitea
integration connection. See the [Gitea overview](/integrations/gitea) for
authentication and setup.

## Payload

Shipfox passes the raw Gitea webhook body to a run as `event`. Gitea owns the
payload schema and can add fields. See the [Gitea webhook
reference](https://docs.gitea.com/usage/repository/webhooks/) for the push
payload schema.

## Trigger fragment

Replace `gitea_shipfox` with the slug of your Gitea integration connection:

```yaml
triggers:
  on_push:
    source: gitea_shipfox
    event: push
```

For trigger field rules, see the [workflow schema reference](/reference/workflow-schema#trigger-fields).
