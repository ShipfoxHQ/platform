Linear connects a Linear workspace to Shipfox. Agent steps can use selected
Linear tools through the integration connection.

## Categories and related terms

**Category:** Issue tracking.

**Related terms:** Issues, tickets.

**Availability:** Available.

## Authentication

Shipfox uses Linear OAuth. Authorize the Shipfox app for the target Linear
workspace. The OAuth flow requests `read`, `write`, `app:assignable`, and
`app:mentionable` access.

## Integration connection identity

The slug of a Linear integration connection defaults to
`linear_<organization>`, where `<organization>` is the Linear organization URL
key. For example, `linear_acme`. Shipfox normalizes the key, falls back to
`linear` when it is unavailable, and makes the slug unique within the workspace.
Use it as `connection` in an agent integration selection.

```yaml
integrations:
  - connection: linear_acme
    include: [list_issues]
```

For the agent integration contract, see the [workflow schema reference](/reference/workflow-schema#agent-integration-fields).
